# Support

For help with Timestamps & Summaries for YT, email [hlbkomer@gmail.com](mailto:hlbkomer@gmail.com) or [open a GitHub issue](https://github.com/Hlbkomer/YouTube-Timestamps-and-Summaries/issues).

Current release: [version 1.2](https://github.com/Hlbkomer/YouTube-Timestamps-and-Summaries/releases/tag/v1.2).

## Setup

- Use Safari on macOS 26.4 or later.
- Move the app to Applications, open it, and enable the extension in Safari Settings.
- Open a YouTube watch or live page. Generated chapters and summaries need captions or an available transcript.
- YouTube-provided chapters work without a cloud-provider connection.
- Apple Intelligence can provide local summaries on a compatible Mac.
- For cloud generation, connect ChatGPT or Grok, or add your own Google AI Studio API key for Gemini. Gemini API usage is billed to your Google project.
- Choose Chapters and Summary models independently in the companion app.

## Reporting a problem

Include the app, macOS and Safari versions, selected provider/models, the error message, and a video URL if it is safe to share. Tell us whether the provider shows as connected and whether Apple Intelligence is available.

Do not include API keys, sign-in tokens or private account information in support requests.

## Known limitations

- Generated output can be incomplete or inaccurate.
- YouTube controls caption, transcript and chapter availability; livestream captions can take time to become available.
- Changes to YouTube, macOS, Safari or the selected provider can affect the extension.

See the [privacy policy](https://hlbkomer.github.io/YouTube-Timestamps-and-Summaries/privacy.html) for data handling and provider controls.
